# Installation

shades2shapes needs Python ≥ 3.9 with numpy, scipy, scikit-image, scikit-learn, pandas
and matplotlib. They are installed automatically.

From the root of the repository:

```bash
pip install .            # regular install
pip install -e .[test]   # editable install, with pytest
pip install .[geo]       # with xarray, rioxarray, netCDF4 and zarr, for satellite images
```

The `geo` extra is needed for georeferenced inputs: xarray objects, GeoTIFF and NetCDF
files (see {ref}`satellite-images`), and Zarr pyramids (see {ref}`pyramids`).

This installs the `shades2shapes` command and its short alias `s2s`:

```bash
shades2shapes --version
```

## Running the tests

```bash
pytest tests/
```

The tests use synthetic spirals and meshes. They check eddy localisation, metric ranges,
two-class, grouped and three-class discrimination, and the command line.

## Building this documentation

```bash
pip install -e .[docs]
make -C docs html        # output in docs/build/html/index.html
```

The example notebook is executed during the build (about 30 s) and its outputs are
cached in `docs/build/.jupyter_cache`, so it only runs again when it changes.

The logos and icons are generated by `docs/source/_static/make_logo.py`.
